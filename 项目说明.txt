项目说明（给以后维护这个程序的人看）
════════════════════════════════════════════

一、你日常要用的是哪里
　dist\时间统计\　　　　　← 绿色版程序，双击 TimeStats.exe 就能用
　（桌面上还有个「时间统计」快捷方式，指向这里）

　其余文件夹都可以不看。


二、各个文件夹是干什么的
　src\　　　　　程序源码（改功能就改这里）
　scripts\　　　开发脚本：打包、测试、生成图标
　vendor\　　　 开发时用的 Electron 运行环境（348MB）
　　　　　　　　只有改代码、跑测试时才用得到。
　　　　　　　　想省空间可以整个删掉，需要时运行：
　　　　　　　　node scripts\extract-electron.js 　就会重新解压出来。
　dist\　　　　 打包产物


三、以后想改功能，怎么重新打包
　1. 装好 Node.js（本机已有）
　2. 在项目根目录执行：
　　　　node scripts\build.js
　3. 等它跑完，dist\时间统计 就是新的程序。
　注意：打包前先把正在运行的程序退出，否则改不了文件名。

　★ 打包脚本只替换运行环境文件，data 文件夹（你的历史记录）原地不动。
　　以前这里是「整个目录删掉重建」，会把记录一起清空，已经改掉了。
　　改这个脚本时别退回那种写法。


四、代码结构（想改哪块看这里）
　src\main\main.js　　　　　　　程序入口：单实例锁、托盘、睡眠、启动恢复
　src\main\ipc.js　　　　　　　 界面能调用的所有功能（通道清单）
　src\main\services\
　　tracker.js　　　　　　　　　★ 计时状态机（判活、去抖、启动器交接、中断扣除）
　　process-scan.js　　　　　　 ★ 进程扫描（CSV 解析、GBK 中文名、进程号带名字）
　　process-detail.js　　　　　 按需查进程真实路径（只在撞名、交接时才调）
　　logger.js　　　　　　　　　 诊断日志（写 data\debug.log，2MB 轮转留 3 份）
　　launcher.js　　　　　　　　 启动程序 / 强制关闭
　　sessions.js　　　　　　　　 流水账（一行一次使用）
　　stats.js　　　　　　　　　　统计口径（跨天拆分、休眠扣除）
　　apps.js　　　　　　　　　　 软件库、读 exe 名字和图标
　　icon-extract.js　　　　　　 图标提取（256px → 32px → 首字母）
　　autolaunch.js　　　　　　　 开机自启（启动文件夹快捷方式）
　　ps\proc-detail.ps1　　　　　被 process-detail.js 调用，输出 pid/名字/路径
　src\renderer\　　　　　　　　 界面（原生 HTML/CSS/JS，没有框架）
　　js\library.js 库　　js\detail.js 详情　　js\stats.js 统计
　　js\settings.js 设置　js\charts.js 图表　js\app.js 总控


五、自带的自检脚本
　node scripts\probe.js　　　　　　 检查进程扫描是否正常
　node scripts\test-stats.js　　　　检查跨天拆分等统计算法
　node scripts\test-tracker-logic.js　检查去抖、交接、防进程号复用、中断扣除
　　　　　　　　　　　　　　　　　　（用假进程表跑，不用启动任何真实程序）
　（还有几个 GUI 测试，需要 vendor 里的运行环境，不常用）


六、几个关键约定（改代码时别破坏）
　· 数据只写在 data\ 里，程序其他文件不改
　· data\sessions.ndjson 只追加、不改写（删单条、改归属时才整体重写）
　· 结束时间取「最后一次看到进程 + 半个轮询周期」，避免系统性少算
　· 跨天会话在统计时才拆分，存储里保留真实的开始/结束
　· 自动监视默认关闭；用户打开后，启动程序时必须立刻 ensureTimer()
　· 判活必须同时核对进程号和进程名
　　（只核对号的话，进程号被系统回收再分配时会以为程序还开着）
　· 自动监视要走 CANDIDATE 观察期（默认 5 秒），
　　别退回「一看到进程就建会话」
　· 轮询分三档：计时中 3 秒、只开监视 10 秒、都没有就不轮询
　　（别退回固定 3 秒，一天会多跑一万多次 tasklist）
　· 查进程真实路径要调 PowerShell（约 1.5 秒），
　　只能低频或按需，不能塞进每一轮巡检
　　（这里以前出过 bug：开机自启后不监视）
